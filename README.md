# AdaBoost College Admission Prediction

Machine learning project to predict college admission status using the AdaBoost algorithm.

## Dataset
genz_college_admission_prediction.csv

## Model
- Algorithm: AdaBoostClassifier (scikit-learn)
- n_estimators: 50
- Train/Test split: 80/20

## Result
- Accuracy: 0.89245

## Tech Used
Python, Pandas, Scikit-learn, Jupyter Notebook

## Files
- adaboost.ipynb: model training and evaluation
- adaboost.pkl: saved trained model
